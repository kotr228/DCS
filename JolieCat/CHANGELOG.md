# Changelog

## 4.0.0 — 2026-11

The first release as a standalone app: one `JolieCat.exe` with .NET inside, nothing to
install first.

### New
- **Interface languages**: English, Ukrainian and Russian, switched on the menu bar or in
  Edit → Preferences, at once and without a restart.
- **Help → About JolieCat** shows the version.
- **Editor**: layer groups, text and type on a path, layer styles, adjustment and fill
  layers, Smart Objects and Smart Filters, artboards, Liquify, Puppet Warp, Camera Raw,
  Blur Gallery, Content-Aware Fill / Move / Scale, Select Subject / Sky / Focus Area,
  Select and Mask, Actions and Batch, Photomerge, Merge to HDR, Auto-Align, Vanishing
  Point, color modes (Grayscale, Bitmap, Indexed), Apply Image and Calculations, all the
  Photoshop blend modes, and many more filters and adjustments.
- **Clipbar Animation**: frame-by-frame frames with onion skin, keyframes with easing,
  motion paths, bones, a camera track, wiggle, motion blur, markers, sound, and GIF /
  APNG / MP4 export.
- **Sprite Sheets**: grid detection, pivots, row names, packed atlases, atlas import and
  game-engine export.
- Editable keyboard shortcuts (Help → Edit Keyboard Shortcuts).

### Improved
- The window opens maximized and fits the screen's work area (the taskbar stays visible).
- One accent color from the logo throughout; restyled sliders, check boxes, scrollbars
  and tooltips; consistent button sizes.

### Fixed
- Stability fixes across saving, undo and filters, including a possible crash of the
  Glowing Edges filter on very wide images.
