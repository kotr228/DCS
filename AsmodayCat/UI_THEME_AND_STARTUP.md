# ASMODAYCAT - BRANDING, ARCHITECTURE & STARTUP (PHASE 13)

## 1. Огляд завдання
Проєкт отримав офіційний логотип та нову кольорову палітру. Необхідно провести глобальний рефакторинг стилів, але **строго дотримуючись архітектури ресурсів та тем, яка вже реалізована в проєкті BlackCat**. Крім того, потрібно додати вікно ініціалізації (Startup Window) за аналогією з іншими програмами нашої екосистеми та підключити існуючу іконку проєкту.

## 2. Затверджена кольорова палітра (HEX)
Усі стилі інтерфейсу повинні базуватися виключно на цих кольорах:
* **#EDCA80** — Фон (світло-пісочний)
* **#E4D3BD** — Базова поверхня карток / панелей (світло-бежевий)
* **#79644D** — Бокове меню навігації / Контури (темно-коричневий)
* **#5E9D55** — Статуси "Онлайн" / Успіх (яскраво-зелений)
* **#BC907E** — Попередження / Додатковий акцент (рожево-коричневий)
* **#BC8F3C** — Головний акцент / Кнопки / Прогрес-бари (золотистий / охра)
* **#1F1A17** — Текст на світлому фоні / Найтемніші елементи (майже чорний)
* **#F9F6F0** — Текст на темному фоні / Світлі відблиски (м'який білий)
